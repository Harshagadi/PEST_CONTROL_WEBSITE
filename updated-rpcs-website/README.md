# Real Pest Control Services – website code

This folder contains the responsive standalone website, original logo, and interactive pest patrol.

## Preview

Open `index.html` in a modern browser. Keep all HTML, CSS, JavaScript files and the `assets` folder together. Google Fonts and GSAP load when an internet connection is available. System fonts and CSS cursor/link effects provide fallbacks when offline.

## Pest patrol

Click or tap a roaming pest to spray it. Use Hide pests to turn the interaction off and Restart to bring them back. The pests remain stationary for visitors who prefer reduced motion.

## Quick chat

The floating Quick chat button opens WhatsApp with the phone number shown on the current site, +91 8801290559. Confirm that this number is registered with WhatsApp before publishing. To use a different number, edit the `wa.me` link in `index.html`. This is a WhatsApp link, not the current site's Wix Chat widget.

## Publish

Upload all files and the assets folder together to a static website host, or give them to your web developer. The current site appears to use Wix, so a developer can recreate the design in Wix or help move the domain to a compatible host. Check business details before publishing.
